## Task 4 - Magic Calc (Modern Calculator)

### Technologies Used

* HTML5
* CSS3 (Custom Properties, Grid, Flexbox)
* JavaScript (ES6+, DOM API, LocalStorage)
* Responsive Design

### Features

* **SaaS-Grade UI:** Modern, polished design with "Space Grotesk" & "Inter" fonts.
* **8+ Premium Color Themes:** Toggle between various light and dark themes (Pink, Blue, Purple, Cyan, Black, etc.).
* **Theme Persistence:** Remembers your color preference using LocalStorage.
* **Full Keyboard Support:** Use your physical keyboard for all operations.
* **Smart Display:** Shows current and previous operations simultaneously.
* **Division by Zero Protection:** Elegant error handling for invalid operations.
* **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.

### Project Folder

```bash
calculator-app
```
